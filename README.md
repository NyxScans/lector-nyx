# Lector Nyx

App oficial de **NyxScans** para leer manhwas en Android.

## Descargar
Último APK: [Releases](https://github.com/NyxScans/lector-nyx/releases/latest)

## Instalar
1. Descarga el APK.
2. Permite "instalar apps desconocidas" si Android lo pide.
3. Abre **Lector Nyx**.

## Requisitos
- Android 8+ (API 26+)

## Actualizaciones
La app comprueba `app_latest.json` (este repo) y avisa si hay versión nueva.
